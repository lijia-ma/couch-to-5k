# Couch to 5K Timer

A simple, mobile-friendly browser timer for the [NHS Couch to 5K running plan](https://www.nhs.uk/better-health/get-active/get-running-with-couch-to-5k/couch-to-5k-running-plan/).

**Live site:** https://lijia-ma.github.io/couch-to-5k/

Based on the NHS Couch to 5K plan. This project is not affiliated with or endorsed by the NHS.
